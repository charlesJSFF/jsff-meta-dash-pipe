==================================================
NOTES ON metric_type PARAMETER
==================================================

The test progression across 3 script versions:

v1 (period only, no metric_type):
  - reach, follower_count, online_followers returned data
  - 12 metrics said "should be specified with parameter
    metric_type=total_value"

v2 (metric_type alone, no period):
  - All said "The parameter period is required"
  - metric_type=time_series said "incompatible with metric type"

v3 (metric_type + period=days_28 or lifetime together):
  - 12 metrics said "period incompatible"
  - Only the original 3 metrics worked

v4 (added period=day tests):
  - period=day alone: still says "needs metric_type=total_value"
  - period=day + metric_type=total_value: SUCCESS for all 12!
  - days_28/lifetime + total_value: still fails for all 12

Conclusion: The pattern for interaction/profile-type metrics at
the IG account level is:
  metric_type=total_value AND period=day  (both required)
No other period grain works.
