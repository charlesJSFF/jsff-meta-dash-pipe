   No account-level Insights metric produces a genuine cumulative/lifetime
   follower total -- confirmed, not inferred, via the live enumerated valid-
   metric-name list in (1) above, plus the period-rejection results for
   follower_count in the DETAIL section below. The only mechanism this run
   found that returns a true cumulative total is the IG User node's
   `followers_count` FIELD (item 4 above) -- a live snapshot at query time,
   not a historical/insights value, and not backed by any period or date
   range. Whether/how to use that field (e.g. daily snapshotting to build a
   history) is an extraction-design decision, explicitly NOT made here --
   flagging it as the concrete option for a later session to evaluate.
